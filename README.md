# Pokémon O.W. RGB

This is a fangame based on the disassemblies of Pokémon Red and Blue.

To set up the repository, see [**INSTALL.md**](INSTALL.md).

## Features

- The game is fully open world, allowing players to tackle Gyms in any order. Although it still starts in Pallet Town, you can ignore Brock's Gym and just go directly to Cerulean City.
- It contains level scaling. After defeating each gym leader, as well as Giovanni's encounters, levels for wild Pokémon, gift Pokémon and Trainers will go up.
- HMs were replaced by items. They're obtainable in the same or similar way as the HMs were in the original games.
- All Pokémon are available to be caught.
- There is a post-game facility to acquire otherwise unobtainable Pokémon (Starters, Eevee, Fossils, Hitmons)
- Moltres has its own dungeon located north of Route 16.
- Prof. Oak can be challenged after completing the Dex.
- There's an additional gift given out by an aide in Route 18's gate that increases exp. and money gained, as well as odds of catching Pokémon in the Safari Zone.
- Some beta elements have been readded/reinterpreted. Chief can now be found in the Safari Zone and fighting him is a step on Team Rocket's storyline.
- There's an additional event with Game Freak employees in Celadon Mansion (now Carrot Tower).
- The Exp. All now splits Exp evenly among all Pokémon in the party. Half goes to the active Pokémon, the other half goes to the benched Pokémon.
- There is a Capsule Machine in the Game Corner that can be used to get TMs 01 through 50 at random.
- The HM moves are now TMs that can be bought in Silph Co. after freeing it from Team Rocket.
- A new item, Link Cable, can be used to evolve trade evolution Pokémon. It can also be bough at Silph Co.

## Moves and Movesets changes
- Barrage is now a 20 BP Grass type move with increased accuracy.
- Vicegrip is now a Bug type move.
- Crabhammer is now a 120 BP move with increased accuracy.
- Charizard and Scyther can learn Fly through TM.
- Lickitung knows Lick from the start.
- Kadabra and Alakazam learn Kinesis at lv24.

## Gameplay Notes & Spoilers
- Levels increase by 5 after each milestone, those being defeating Gym Leaders, Chief and Giovanni.
- Team Rocket's storyline is done linearly, it has changed slightly: ```it starts by defeating all Rocket Grunts in Mt. Moon. Only after defeating all of them the Game Corner hideout will be available to tackle. To enter Silph Co., it's need both to save Mr. Fuji in Lavender Town, as well as defeating Chief in the Safari Zone. Giovanni's Gym is unlocked right after defeating him in Silph Co. Mewtwo is unlocked after defeating Giovanni in Viridian Gym.```
- Game Freak's side quest starts after talking to the Game Director in GF's office: ```it requires players to find staff members around Kanto. The Programmer is found in Silph Co., the Musician is found in Route 12, the Character Designer is found in Celadon Dept. Store 3F, the Pokémon Designer is found in Safari Zone Center Safe House and the Map Designer is found in Fuchsia City. Completing this quests unlock the diploma after dex completion. Talking to the Programmer again after becoming Champion will also unlock Mew's event```
